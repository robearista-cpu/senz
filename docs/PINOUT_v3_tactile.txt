================================================================================
 SENZ GLOVE — HARDWARE SPRINT v3 (TACTILE-FIRST)  PIN LAYOUT
 Board: ESP32-S3-DevKitC-1        Sketch: firmware/senz_glove_v3_tactile/
================================================================================

 GOAL of this sprint: get the TACTILE (velostat force) data down solid + capture
 GROSS hand movement. Finger articulation is deferred to CAMERA capture
 (host/camera_tracker.py) later. So the on-glove IMU set is minimal.

 WHAT IS / ISN'T USED (clears up the multiplexer question):
   - CD74HC4067 analog mux .... USED, for the velostat taxels ONLY.
   - TCA9548A I2C mux ......... NOT used this sprint.
   - 74HC595 / any SPI mux .... NOT needed (only ONE SPI IMU -> one direct CS).

 All sensors run at 3.3V logic. NEVER connect 5V to any GPIO or to a common
 electrode. Power in: 5V USB power bank -> 5V header pin -> onboard reg -> 3V3.

 Sensor set:
   - wrist  : 1x BNO055   (I2C)  forearm reference — BNO055 has NO SPI mode
   - dorsum : 1x MPU-9250 (SPI)  back-of-hand / palm frame (9-axis; mag not read)
   - force  : 15x Velostat taxels via CD74HC4067 analog mux -> 1 ADC pin
   wrist-flex angle = forearm (BNO055) vs hand (dorsum).

--------------------------------------------------------------------------------
 BUSES
--------------------------------------------------------------------------------

 I2C  (BNO055 wrist IMU, 400 kHz)
   ESP32-S3 GPIO8  -> SDA
   ESP32-S3 GPIO9  -> SCL

 SPI  (single dorsum IMU, Mode 3, 8 MHz)
   ESP32-S3 GPIO11 -> MOSI / SDI   (data to sensor)
   ESP32-S3 GPIO12 -> SCLK         (clock)
   ESP32-S3 GPIO13 -> MISO / SDO   (data from sensor)
   ESP32-S3 GPIO4  -> NCS          (chip select, active low)

================================================================================
 DORSUM IMU (x1, MPU-9250) — module pin -> connection
================================================================================
 MPU-9250 / MPU-6500 breakouts wire IDENTICALLY for SPI. The breakout labels are
 I2C-style but pins are used as SPI:

   PIN     ROLE (SPI mode)         CONNECT TO
   -----   ---------------------   ------------------------------------------
   VCC     3.3V power              3V3 rail
   GND     ground                  GND rail
   SCL     SPI clock  (SCLK)       GPIO12
   SDA     SPI data in (SDI/MOSI)  GPIO11
   AD0     SPI data out (SDO/MISO) GPIO13
   NCS     chip select (active LO) GPIO4
   EDA     aux I2C master SDA      not connected  <-- NOT the SPI bus
   ECL     aux I2C master SCL      not connected  <-- NOT the SPI bus
   INT     data-ready interrupt    not connected (firmware polls at 200 Hz)
   FSYNC   frame sync              GND (tie low — unused, do not leave floating)

 Firmware accepts WHO_AM_I 0x71 (9250) AND 0x70 (6500), so either chip works as
 the dorsum. Mount it FLAT on the BACK OF THE HAND over the index/middle
 metacarpals (the knuckle area) — this is the hand/palm reference frame.

================================================================================
 BNO055  (x1, wrist reference IMU) — module pin -> connection
================================================================================

   PIN       ROLE                 CONNECT TO
   -------   ------------------    ------------------------------------------
   VIN       3.3V power            3V3 rail
   GND       ground                GND rail
   SCL/RX    I2C clock             GPIO9   (shared I2C SCL)
   SDA/TX    I2C data              GPIO8   (shared I2C SDA)
   AD0       I2C address select    GND  -> address 0x28 (matches firmware)
   INT       interrupt out         not connected
   BOOT      boot / mode (PS1)     not connected (default = I2C mode)
   REST      reset (active low)    not connected (internal pull-up)

 Mount on the FOREARM just behind the wrist.

================================================================================
 VELOSTAT FORCE ARRAY (15 taxels) via CD74HC4067 analog mux  <-- THE DELIVERABLE
================================================================================
 15 pads: thumb 2x2 -> C0..C3,  index 2x2 -> C4..C7,  middle 2x2 -> C8..C11,
 palm -> C12 center / C13 thenar / C14 hypothenar.  (C15 free for expansion.)
 One shared divider resistor at the mux common; only one channel is connected
 at a time, so a single resistor serves all 15.

   Divider (per selected pad):

     3V3 -- common faraday -- [ velostat pad ] -- top pad -- Cn
                                                              |
                              mux COM/SIG --------------------+-- GPIO10 (ADC1)
                                          |
                                          +-- 10k..22k -- GND        (divider R)
                                          +-- 1..10nF  -- GND        (optional filter)

   CD74HC4067 pin   ->  ESP32-S3
   --------------       ----------------------------------------------------
   VCC              ->  3V3
   GND              ->  GND
   SIG (COM)        ->  GPIO10   (ADC1_CH9)  + the 10k..22k resistor to GND
   EN  (enable)     ->  GND      (active-low; grounded = always enabled)
   S0               ->  GPIO6    (channel-select bit 0)
   S1               ->  GPIO7    (bit 1)
   S2               ->  GPIO15   (bit 2)
   S3               ->  GPIO16   (bit 3)
   C0..C3           ->  thumb pads (2x2)    top-pad wires
   C4..C7           ->  index pads (2x2)    top-pad wires
   C8..C11          ->  middle pads (2x2)   top-pad wires
   C12              ->  palm center          top-pad wire
   C13              ->  palm thenar (thumb-side mound)
   C14              ->  palm hypothenar (pinky-side mound)
   C15              ->  unused (leave open)

   Common faraday plane(s)  ->  3V3   (shared by all pads)

 IMPORTANT: use ADC1 (GPIO1..GPIO10) for SIG — never ADC2. ADC2 stops working
 when BLE/WiFi is on, and BLE is on the roadmap. GPIO10 is ADC1, so it's safe.

 Firmware reliability touches (senz_glove_v3_tactile.ino): 8 us settle after each
 mux channel switch + 6-sample average per taxel; the host force_pipeline.py adds
 baseline drift removal + low-pass on top.

================================================================================
 PIN USAGE SUMMARY / CONFLICT CHECK
================================================================================
   SPI bus        : GPIO11, GPIO12, GPIO13
   Dorsum IMU CS  : GPIO4
   I2C bus        : GPIO8,  GPIO9
   Mux select     : GPIO6,  GPIO7, GPIO15, GPIO16
   Mux SIG (ADC1) : GPIO10
   -> all distinct, all legal ESP32-S3 pins, no boot-strapping conflicts.

 FREE GPIOs REMAINING: GPIO5, 14, 17, 18, 21, 38, 39, 40 (+ others).  Plenty of
 headroom to add finger IMUs later (a 74HC595 CS expander) or more taxels.
